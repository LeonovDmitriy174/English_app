# Встроенные книги

Сюда кладутся EPUB-книги, которые приложение предлагает «из коробки»: на телефоне они появляются в папках
на экране «Книги». Нажали на книгу, она один раз скачалась на устройство и дальше читается без интернета.

## Как добавить книги

1. Положите файлы `.epub` в эту папку.
   - Файлы прямо в `books/` попадают в папку «Встроенные» (внутри это `default`).
   - Подпапка — вложенная папка внутри «Встроенных». Например, `books/Детям/alice.epub` даст «Встроенные › Детям».
   - Вложенность одна: папка внутри подпапки (`books/Детям/Сказки/…`) отдельной папкой не станет. Книги из неё попадут
     в «Детям», а `python tools/build_catalog.py` напомнит об этом.
2. Посмотреть результат на компьютере (необязательно): `python tools/build_catalog.py`, затем `npm run serve`.
3. Сделайте commit и push. GitHub Actions сам соберёт список книг и обложки и опубликует их вместе с приложением.

Файлы `catalog.json` и папку `covers/` создавать и коммитить не нужно: они собираются из книг заново.

## Названия папок

Необязательный файл `books/groups.json` задаёт названия и порядок папок. Ключ — имя подпапки (или `default`
для книг прямо в `books/`), значение — название в приложении:

```json
{
  "default": "Для Сони",
  "Детям": "Детям",
  "classics": "Классика"
}
```

Без этого файла папки называются по именам подпапок. «Встроенные» всегда первая, за ней вложенные в порядке из файла,
остальные по алфавиту.

На телефоне внутри «Встроенных» можно создавать и свои вложенные папки: они хранятся только на телефоне и в `books/` не
попадают.

## Только то, что можно распространять

Репозиторий открытый, поэтому любой человек может скачать любую книгу из этой папки. Кладите сюда только
книги без авторских прав: произведения, перешедшие в общественное достояние, и книги под свободной лицензией.
Хорошие источники: [Project Gutenberg](https://www.gutenberg.org), [Standard Ebooks](https://standardebooks.org),
[Wikisource](https://wikisource.org). Книги, защищённые авторским правом (например, о Гарри Поттере), в
репозиторий не кладите. Такие книги можно добавлять прямо в приложении кнопкой «+»: они остаются только на вашем телефоне.

Размер: GitHub Pages принимает сайт до 1 ГБ, а один файл в репозитории не может быть больше 100 МБ.
Обычная книга занимает от 100 КБ до нескольких МБ.
