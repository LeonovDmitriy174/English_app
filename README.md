# Ember Chronicle

Личное приложение для изучения английского через чтение книг. Работает как сайт, который ставится на экран iPhone и после первой загрузки **не нуждается ни в сети, ни в подписках, ни в чужих серверах**.

Рабочее название `Ember Chronicle` лежит в одной константе: `APP_NAME` в `js/store.js` (плюс `<title>` и `manifest.webmanifest`). Переименовать можно в любой момент.

## Что умеет первая версия

- **Чтение EPUB.** Книга загружается файлом прямо на устройство (кнопка «+» в библиотеке). Оглавление, обложка, позиция чтения запоминаются.
- **Нажал на слово: карточка.** Перевод, определение, предложение из книги с выделенным словом, пример, произношение (голос iOS).
- **Фразовые глаголы и идиомы находятся сами**, в том числе разорванные: *wake … up*, *woken up*. Они подчёркнуты пунктиром в тексте; нажатие на любое слово фразы открывает карточку фразы, а внизу есть «Только слово: …».
- **Словарь.** Поиск, фильтры «Слова / Фразовые глаголы / Идиомы», срок следующего повторения у каждой карточки.
- **Повторение по «лесенке» интервалов, дальше алгоритм FSRS-5.** Режимы: карточки, написание по переводу, слово в предложении (пропуск в предложении из вашей книги) и «Микс». Оценки «Снова / Трудно / Хорошо / Легко» показывают, через какое время вернётся карточка. Подробности в разделе «Как устроены повторения».
- **Настройки:** тема (системная, светлая, тёмная), размер текста, подсветка фраз, озвучка при нажатии, лимит новых слов в день, резервная копия.

## Как поставить на iPhone

Приложение нужно один раз «выложить» на бесплатный хостинг статических файлов, как почтальона, который передаёт файлы на телефон. После этого оно живёт в телефоне.

GitHub Pages:

1. Код лежит в репозитории на GitHub (из PyCharm: Git → GitHub → Share Project on GitHub). Для бесплатного аккаунта репозиторий должен быть **публичным**: Pages на бесплатном тарифе работает только так. В репозитории только код и демонстрационный словарь: ваши книги и словарь туда не попадают, они хранятся в памяти телефона.
2. На GitHub: **Settings → Pages → Source: GitHub Actions.** Файл `.github/workflows/pages.yml` уже в проекте. Откройте вкладку **Actions**: там должен выполниться запуск «Опубликовать приложение» (зелёная галочка, 1–2 минуты). Если не запустился сам, нажмите **Run workflow**.
3. Адрес сайта: `https://ваш-логин.github.io/название-репозитория/` (он же показан в Settings → Pages и в запуске workflow).
4. Откройте адрес на iPhone в **Safari**, нажмите «Поделиться» → **«На экран „Домой“»**.
5. Откройте приложение с экрана «Домой» один раз при включённом интернете. Дальше оно работает в режиме полёта.

Android: тот же адрес открывается в Chrome, меню → «Установить приложение». Компьютер: тот же адрес в любом браузере.

### Как обновляется телефон

Коротко: **вы пушите в репозиторий, остальное происходит само, но перезапуск приложения делаете вы.**

1. Вы делаете commit и push в ветку `main` (PyCharm: Git → Commit → Commit and Push).
2. GitHub Actions за 1–2 минуты публикует новую версию и сам подставляет в `sw.js` номер коммита. Менять версию вручную не нужно.
3. Телефон проверяет обновления, когда вы открываете приложение или возвращаетесь в него. Нужен интернет.
4. Новая версия скачивается в фоне, внизу появляется плашка **«Доступна новая версия» → «Обновить»**. Нажмите, когда удобно (в середине повторения можно закончить его).
5. Книги, словарь и прогресс не затрагиваются: они в отдельном хранилище, а обновляется только код.

Если телефон давно без интернета, он просто продолжает работать на старой версии.

Если вы не включили Actions и публикуете «из ветки» (Settings → Pages → Deploy from a branch), приложение тоже обновится: без номера версии оно работает в режиме «сначала сеть, кэш на случай офлайна». Так же работает запуск на компьютере.

## Данные и резервные копии

- Всё лежит в IndexedDB браузера: книги (файлом), карточки, расписание повторений, журнал ответов, настройки.
- Установленное на «Домой» приложение iOS не чистит по семидневному правилу, как обычные сайты, но удалить данные может при критической нехватке места или при удалении иконки.
- **Раз в неделю-две делайте копию:** Настройки → «Сохранить копию данных» (файл `ember-backup-ДАТА.json`, сохраните его в «Файлы»/iCloud). В копии карточки, расписание, журнал, настройки и позиции в книгах. Сами EPUB в копию **не входят** (они большие): загрузите их заново, и позиция чтения подхватится автоматически.
- Восстановление: Настройки → «Загрузить копию данных».

## Как устроены повторения

Новая карточка проходит такие шаги, пока вы отвечаете «Хорошо»:

```
1 мин → 10 мин → 1 день → 3 дня → 7 дней → 14 дней → дальше считает FSRS (обычно 1–2 месяца, потом дольше, максимум год)
```

- **Хорошо:** следующая ступень.
- **Легко:** через одну ступень (например, с 3 дней сразу на 14).
- **Трудно:** повторить ту же ступень (на новой карточке: через 6 минут).
- **Снова:** через 10 минут, а потом возврат на две ступени назад (с 14 дней на 3, с 3 дней на 1).
- Если вы пришли позже срока и успели «пропустить» ступень, карточка поднимается выше.
- После ступени 14 дней рост ограничен: «Хорошо» даёт не больше чем втрое от прошлого интервала.
- **Сутки начинаются в 4:00.** Карточка «через 1 день» готова с самого утра следующего дня, а не через ровно 24 часа. Так вечерние повторения не «уезжают» вперёд.

Лесенка настраивается в одной строке: `ladder` в `DEFAULTS` в `js/fsrs.js`. Пустой список `[]` включает чистый FSRS. Стабильность и сложность по формулам FSRS обновляются на каждом ответе, поэтому переход к FSRS после 14 дней получается плавным.

## Словарь: честное состояние

Подсказки для нажатий берутся из файла `data/dict.json`. Сейчас это **демонстрационный глоссарий на 229 записей, написанный вручную под вторую главу «Гарри Поттера»**: 158 слов, 31 фразовый глагол, 40 идиом. В остальных главах и книгах приложение отмечает слово как «нет в словаре» и предлагает ввести перевод самому; он сохранится в карточку вместе с предложением.

Как добавить записи вручную: строка в `data-src/glossary.psv`

```
тип|заголовок|часть речи|перевод|определение|пример|шаблоны;|формы;|флаги
```

затем `python3 tools/build_dict.py` и запушить изменения. Типы: `w` слово, `pv` фразовый глагол, `id` идиома. В шаблонах: `@` означает притяжательное (*lose @ temper*), `*` любое одно слово, флаг `sep` разрешает разрыв фразового глагола (*pick the book up*).

## Следующий большой шаг: автоматический словарь

Чтобы любая книга работала без ручной подготовки, нужен офлайн-конвейер на вашем ноутбуке (в телефон он не входит):

1. Разбор текста книги (spaCy или похожий инструмент), нахождение лемм, фразовых глаголов и идиом.
2. Список слов по частотности (wordfreq), чтобы не показывать «the» и «is» и отметить редкие слова.
3. Переводы и определения из локальной копии Wiktionary, перевод предложений офлайн-моделью (Opus-MT).
4. Результат: готовый `dict.json` под вашу книгу или общий словарь на 30–50 тыс. записей, который кладётся в приложение.

Нейросеть обучать не нужно: всё это готовые инструменты, которые запускаются локально и без подписок.

## Для разработчика

```
index.html, manifest.webmanifest, sw.js   оболочка PWA и офлайн-кэш
css/app.css                               дизайн-система «pencil reader»
js/lex.js                                 леммы, токены, поиск фраз, предложения
js/fsrs.js                                лесенка интервалов + планировщик FSRS-5 (написан вручную)
js/zip.js, js/epub.js                     чтение EPUB без библиотек
js/db.js, js/store.js                     IndexedDB и состояние приложения
js/views/*.js                             экраны: библиотека, читалка, карточка, словарь, повторение, настройки
data/dict.json                            словарь (собирается из data-src/glossary.psv)
tests/                                    node --test tests/*.test.mjs  (29 тестов)
.github/workflows/pages.yml               публикация на GitHub Pages и штамп версии
tools/                                    build_dict.py, make_icons.py
```

Локальный запуск: `python3 -m http.server 8080` в папке проекта, затем http://localhost:8080 (service worker работает на localhost).

Известные ограничения: FSRS (часть после лесенки) написан по описанию алгоритма с весами по умолчанию и пока не сверен с эталонной реализацией (`ts-fsrs`); системные шрифты (на iOS заголовки и текст набираются New York и San Francisco); озвучка использует голоса iOS: лучшие из них (Enhanced/Premium) скачиваются в Настройки iOS → Универсальный доступ → Устный контент → Голоса.

## История версий

- **v2.** Лесенка интервалов 1 мин → 10 мин → 1/3/7/14 дней, дальше FSRS; сутки начинаются в 4:00. Автоматическая публикация и номер версии (GitHub Actions), плашка «Доступна новая версия». Резервная копия стала независимой от названия приложения и возвращает позицию в книге после повторной загрузки EPUB. Уведомления теперь сверху экрана.
- **v1.** Первая версия: читалка EPUB, карточки слов, фразовые глаголы и идиомы, словарь, три режима повторения, офлайн.
